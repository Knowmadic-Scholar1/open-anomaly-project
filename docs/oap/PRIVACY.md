# OAP Privacy

- Do not track named people as surveillance targets.
- Do not expose exact observer home locations by default.
- Observation locations support: exact internal, public fuzzing, neighborhood-level display, privacy radius.
- Prefer: "Observation submitted from this approximate area."
- Do not build civilian movement histories from observation points.
- Anonymous browse of public events is first-class.
- Sensor capture is opt-in per observation session.
