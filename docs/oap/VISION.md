# Open Anomaly Project — Vision

The **Open Anomaly Project (OAP)** is a free, open-source, mobile-first citizen-science network for reporting, observing, investigating, corroborating, mapping, and attempting to explain unusual real-world events.

The **Open Anomaly Protocol** is the transport-neutral technical specification that lets humans, apps, sensors, and AI agents exchange anomaly events and evidence.

## Core object

The core object is an `AnomalyEvent`, not a `UFOReport`.

The platform investigates claims and attempts to falsify or explain them. **Unresolved** means available evidence is insufficient — it does **not** mean extraterrestrial, supernatural, or interdimensional.

## Principles

1. Anyone can observe.
2. Anyone can investigate.
3. Anyone can browse public evidence.
4. AI is optional.
5. Agents are optional.
6. Phones can act as voluntary scientific instruments.
7. Evidence outweighs popularity.
8. Independent sources outweigh repeated opinions.
9. Unknown / unresolved remains a valid conclusion.
10. Resolved / debunked events remain in the database.
11. Conclusions remain challengeable when new evidence appears.
12. Provenance is preserved.
13. Privacy is designed in from the start.
14. Do not track named people.
15. Do not create civilian-surveillance features.
16. Users do not need to understand AI to use the platform.
17. OAP remains useful even if no AI agent ever connects.

## Product principle

Do not build OAP to prove extraordinary phenomena exist or do not exist.

Build OAP to make unusual observations **easier to capture, harder to fake, easier to correlate, easier to investigate, and harder to lose.**

## Relationship to God's Eye View

God's Eye View remains the world visualization and live geospatial context substrate.

OAP adds anomaly lifecycle, observations, evidence, investigations, alerts, accounts, protocol, and agent interoperability on top of that globe.
