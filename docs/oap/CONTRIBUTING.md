# Contributing to OAP

1. Prefer extending God's Eye View layer/manager patterns over rewrites.
2. Keep the core usable without AI.
3. Do not center exotic conclusions in copy or defaults.
4. Add tests for store, privacy, and permission boundaries.
5. Document third-party data terms when adding sources.
6. Use feature branches; do not push destructive schema to shared non-OAP databases.

See also root [`CONTRIBUTING.md`](../../CONTRIBUTING.md).
