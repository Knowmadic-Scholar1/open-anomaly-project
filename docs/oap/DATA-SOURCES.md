# OAP Data Sources

OAP event records are first-party community/scientific records.

Live context used during investigation may come from God's Eye View integrations. Those feeds keep **their own licenses and terms** — see root [`DATA_SOURCES.md`](../../DATA_SOURCES.md).

OAP MUST:

- attribute third-party context in evidence entries
- store investigation summaries, not wholesale feed archives
- respect non-commercial constraints (e.g. OpenSky) for public deployments
- treat Google Maps tiles as live-only (no caching/rehosting)

OAP community media in V0.1 is reference-only (`media_url` + metadata).
