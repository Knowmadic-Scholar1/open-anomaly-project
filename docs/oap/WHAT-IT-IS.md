# What is the Open Anomaly Project?

> **Make unusual observations easier to capture, harder to fake, easier to correlate, easier to investigate, and harder to lose.**

This short page points newcomers to the **canonical public vision document**:

**→ [`Open_Anomaly_Project.md`](../Open_Anomaly_Project.md)** — mission, principles, boundaries, what OAP should and should not become, and what it could become with community.

## One-sentence mission

Open Anomaly Project exists to create an open, privacy-conscious, scientifically curious network in which anyone can document unusual events, anyone can help investigate them, ordinary devices can contribute meaningful observations, AI can assist without becoming mandatory, and every conclusion remains traceable to the evidence that produced it.

## Quick boundaries

| OAP is | OAP is not |
|--------|------------|
| An `AnomalyEvent` evidence network | A UFO / alien database |
| Observation + independent corroboration | A conspiracy or debunking theater |
| Phones as voluntary instruments | Civilian surveillance of people |
| AI-optional agent hooks | An AI-only product |
| Resolved cases kept forever | A popularity / engagement machine |
| Built on God's Eye View | A rewrite that ignores upstream lessons |

**Unresolved means unresolved** — not extraordinary.
